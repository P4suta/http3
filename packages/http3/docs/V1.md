# Pre-publication product gate

`http3` is the middle package in the unpublished
`http -> http3 -> quic_core` product. It owns HTTP/3, QPACK, Capsules,
HTTP Datagrams, push, priority, GOAWAY, and the HTTP/3 WebSocket adapter. QUIC
packet processing, UDP, TLS, Retry, tokens, and connection actors belong to
`quic_core`; unified HTTP policy and the protocol-neutral server belong to
`http`.

All packages remain version `0.1.0`. This worktree is not a release candidate,
is not independently audited, and must not be described as production-ready.
No repository task tags, publishes, pushes, changes versions, or creates a
hosted release.

## Source of truth

The repository [`qualification.json`](../../../qualification.json) manifest
and generated [product conformance status](../../../docs/CONFORMANCE.md) are
the only current release-status record. Package prose and historical evidence
must not override them. A `Ready` gate has an executable implementation and a
current passing report; `Blocked` names missing local implementation or
evidence; `ExternalPending` is reserved for an independent condition that the
unpublished worktree cannot create.

The normal consistency gate is:

```sh
mise run check
```

The unpublished automated candidate gate is:

```sh
mise run source-candidate
```

That command deliberately fails while coverage, requirement mapping, qlog
event breadth, peer/platform evidence, performance evidence, or another
declared qualification report is incomplete. `mise run release-candidate`
adds the independent-audit attestation and signed-commit checks and returns
nonzero with `ExternalPending` when either external condition is absent.
The check also requires the current source digest to match the completed audit
bundle and rejects a signed `HEAD` when tracked or untracked candidate content
is still outside that commit. Attestations use a detached `gpgv` signature and
the repository's explicit trusted-auditor keyring, as specified by the root
first-publication gate.

## Stable package scope

The package surface preserves the public client, server, streaming,
Datagram, migration, resumption, mTLS, 0-RTT policy, reload, push, GOAWAY,
Capsule, and WebSocket behavior recorded by its compiler API snapshot. HTTP/3
uses only the six audited public `quic_core` modules and opaque connection and
stream values. The source scan, compiler-interface audit, and compiled xref
all require the private-boundary allowlist to remain empty.

WebTransport, multipath QUIC, ACK Frequency, reliable reset, extended key
update, provisional MASQUE codepoints, Internet-Drafts other than the pinned
diagnostic qlog schema, and the JavaScript target are outside the initial
product scope. Raw packet/frame/TLS/socket/actor values, certificate bypasses,
unlimited queues, and unlimited deadlines are intentionally not public APIs.

See [Conformance](CONFORMANCE.md), [Testing](TESTING.md), and
[Security review](SECURITY_REVIEW.md) for package-specific detail. When their
wording conflicts with the generated product status, the generated status
wins.
